BMI Calculator

A Python-based BMI Calculator that calculates Body Mass Index (BMI), classifies the result into standard categories, stores historical records, and displays BMI trends using a graphical interface.

Features
Calculate BMI using weight and height
Display BMI rounded to 2 decimal places
Classify BMI as:
Underweight
Normal
Overweight
Obese
Input validation for invalid and negative values
Tkinter graphical user interface
Colour-coded BMI results
Support for multiple users
SQLite database for storing BMI records
View BMI history
BMI trend visualization using Matplotlib
Database error handling
Technologies Used
Python
Tkinter
SQLite3
Matplotlib
BMI Formula
BMI = Weight (kg) / Height² (m)
BMI Categories
BMI Range	Category
Below 18.5	Underweight
18.5 – 24.9	Normal
25 – 29.9	Overweight
30 and above	Obese
How to Run

Install Matplotlib:

pip install matplotlib

Run the program:

python bmi_calculator.py

The SQLite database will be created automatically when the application runs.

Project Purpose

This project was developed to practice Python programming, GUI development, database management, input validation, and data visualization.
